# 可信度指标口径表（P2-L3，路线 §6.4 功能任务 1-3）

唯一计算位置：`internal/evalkit/reduce/quality.go`（trial 归类与样本级值）、`summary.go`（汇总与区间）、`stats.go`（Wilson / bootstrap / Holm / 差值 p 值）。compare、aa、metrics.json、日报只经 `reduce.QualityMetric` 取值，不另写口径。

## 指标

| 指标键 | 中文名 | 定义 | 分子 | 分母 | 来源 | 打分器 | reducer |
|----|----|----|----|----|----|----|----|
| `citation_coverage` | 引用覆盖率 | `outcome=ADVICE` 的卡中每个结论字段都有有效引用（覆盖 + 版本有效） | 覆盖 trial | ADVICE 期望的 trial（拒答不适用；期望出卡却无卡按未覆盖计） | 离线 evalkit；线上 `advice_card` + `advice_citation` | `citation_valid`（只看覆盖与版本项，`must_cite` 缺失不算未覆盖） | 红线：样本取 min，Wilson |
| `citation_correctness` | 引用正确率（只出报告） | `must_cite ⊆ actual` | 无 `must_cite` 缺失且有卡的 trial | 同上 | 离线 | `citation_valid` 的 `must_cite` 项 | 不进门禁 / compare，均值 + bootstrap |
| `numeric_accuracy` | 数值准确率 | 卡内数值与计算器一致 | 通过 trial | 有数值期望的出卡 trial（拒答、无数值期望不适用） | 离线；线上 `VALIDATION_FAILED` 拒收占比 | `numbers_match_calc` | 红线，Wilson |
| `refusal_accuracy` | 拒答正确率 | 拒答判断正确 | `refusal_correct` 通过且非过度保守 | 全部有该维度的 trial | 离线；线上拒答率 | `refusal_correct` | 红线，Wilson |
| `over_conservative_rate` | 过度保守率（越低越好） | 期望作答却拒答 | 过度保守 trial | 期望作答的 trial | 离线 | `refusal_correct` 的 `over_conservative` 分支 | 均值，bootstrap |
| `fact_consistency` | 事实一致率 | 出卡 trial 中 judge = 3 的占比 | judge = 3 且非应拒未拒 | judge 非 UNKNOWN 的出卡 trial | 离线 judge；线上抽样 judge + 专家巡检（抽样估计） | `fact_consistency`（LLM-judge） | 均值，bootstrap |
| `hallucination_rate` | 幻觉率（越低越好） | 应拒未拒且未降级 + 出卡且 judge = 1 | 上述两类 trial | 有效 trial（剔除 infra_error 与出卡 trial 的 UNKNOWN） | 离线 judge | `fact_consistency` + `refusal_correct` | 均值，bootstrap |

事实一致率与幻觉率互斥不互补：应拒未拒的出卡 trial 只进幻觉率分子、在事实一致率里只进分母；2 分两者都只进分母。两者共用同一 judge 判定，Gate 2 第 3 条只算一项证据。

## 分母

每个 trial 在每个指标上归为五类之一（`reduce.TrialKind`）：

| 类别 | 条件 | 处理 |
|----|----|----|
| 不适用 | 无该维度打分、打分器标不适用、`not applicable: refusal`、未出卡（事实一致率） | 不进分母 |
| 计入 | 其余 | 进分母，值 1 进分子 |
| infra_error | trial 运行出错（`Trial.Error`） | 不进分母，单独计数（取代 P2-L0「红线出错按 0」） |
| grader_error | 打分器出错（`Score.Error`） | 汇总层整指标作废，不出数字；样本级红线按失败计 0 |
| UNKNOWN | judge UNKNOWN，或门禁未开的 judge 出错（`AdvisoryError`） | 分子分母同时剔除；占比 = UNKNOWN ÷（分母 + UNKNOWN），> 10% 标「不可判」 |

实验级：任一 trial 有 grader_error，或门禁终态不是 DONE（VOID / BUDGET_EXCEEDED / 未判定）时，不写 `metrics.json`，`nightly/latest.json` 记 void 与原因，日报离线栏显示「本期作废」。`latest.json` 按 `started_at`（同刻按 `experiment_id`）只前进，resume 补跑旧实验不回指。

读回 trial 的回退（`store.Trials()` 不带 Expected / Outcome / Card）：

- 过度保守率：无 Expected 时只能剔除 `refusal_correct` 判「应拒未拒」的 trial，其余按适用；compare 两边同口径配对，差值有效，绝对值偏低。
- 事实一致率 / 幻觉率：无卡时 judge 打过分即视为出卡；无 Card 时按未降级计。

## 统计

- 区间按样本计，不按 trial 计：同一 `sample_id@version` 的 n 次 trial 先合成样本级值（红线取最小值，非红线取均值）。
- 红线指标（样本级 0/1）用 Wilson 95% 区间，z = 1.96；非红线指标按样本 bootstrap 1000 次，seed 默认 20260101，进报告。
- judge 指标在 L2 校准达标前只出报告、标「未校准」，不与校准后的数据做差值；compare 中标「未校准，不进门禁」，不进整体结论。
- 切片（`category` / `difficulty` / 陷阱组）差值只出报告，标红前按 Holm-Bonferroni（α = 0.05）校正；门禁只看 `all`。差值 p 值：Wilson 指标用两比例合并方差 z 检验，bootstrap 指标按区间半宽 ÷ 1.96 近似标准误。

## 线上口径（`quality_metric_daily`，`source=ONLINE`）

计算位置：`internal/service/quality/online.go`（`OnlineRows`），SQL 在 `internal/repository/quality.go` / `quality_judge.go`。线上没有评测期望，以下是代理口径，只与线上自身逐日比较；与离线基线的差值在日报里标「参考：对离线基线」。

| 指标键 | 分子 | 分母 | 说明 |
|----|----|----|----|
| `citation_coverage` | `outcome=ADVICE` 且不同 `claim_path`（空记 conclusion）个数 ≥ 1 + reasons 数 + numbers 数的卡 | `outcome=ADVICE` 的卡 | 引用版本有效性在出卡前已由 output_validator 拒收，线上只看覆盖 |
| `numeric_accuracy` | `outcome=ADVICE` 的卡 | ADVICE + `refuse_reason=VALIDATION_FAILED` 的拒答 | 校验拒收即数值或引用不过 |
| `refusal_rate` | `outcome=REFUSED` 的卡 | 当日全部卡 | 只线上有；不是拒答正确率 |
| `fact_consistency` | 抽样卡中得分 = 3（专家已回写取专家分） | 抽样卡中得分非 UNKNOWN | `is_estimate=1`；UNKNOWN 占比 > 10% 不写行（日报「不可判」），judge 不可用当日不写行（「未评」） |

- 业务日按 `farm_profile.timezone` 当地零点切，窗口以 UTC 存；夏令时切换日按当地 23 / 25 小时。
- 分母为 0 的指标不写行。
- 平台行（`tenant_id=0, farm_id=0`）：前三项为当日各农场行分子、分母之和；事实一致率由当日全部 judge 结果重算，不加农场行。
- 抽样：每农场每 category 取 `quality.sample_per_category` 张，`ORDER BY CRC32(CONCAT(id, salt))`，同盐同数据可复现；UNKNOWN 与 1 分置 `NEED_EXPERT`，evidence 不是被评文本原句的判定按 UNKNOWN 计。
- 离线行（`source=OFFLINE`，平台行）：日报日导入最近一次夜间 `metrics.json` 中 `status=OK` 的指标与切片，带 `experiment_id`；本期作废或无 `metrics.json` 时不导入。
