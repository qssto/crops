## 1. 维度读法

| 维度 | 读法 |
|------|------|
| 作物 | 顶层 `crop` 字段，须等于 taxonomy `crop`（rice） |
| 生育期 | 顶层 `stage` 字段，取 taxonomy `stages`（七个物候期或 `不限`）；有 `crop.phenology` 桩时须与第一条桩返回的 `stage` 一致 |
| 问题类型 | `tags` 中第一个 taxonomy 子类 code；建议类样本须属于 `expect.advice.category` |
| 难度 | `difficulty`（easy / medium / hard） |

计数口径：不含 holdout 套件（只数文件）和 `user_sim` 样本（单列），隔离样本照计。
