## 上层接口（已冻结，见 internal/agent/{agent.go,seams.go}）
- `agent.Agent.Ask(ctx, Question) (Answer, error)`；Question 新增 `Scope / FieldID / RunID`（RunID=0 时 Ask 自建 agent_run），Answer 新增 `RunID / Card *model.AdviceCard / Order *model.WorkOrder`。
- `RunStateStore{CreateRun(ctx, s, userID, fieldID, RunMeta), LoadRun, SaveStep, FinishRun(ctx, scope, runID, status, reasonCode), Heartbeat}`；`AdviceStore.SaveAdvice(ctx, scope, card) (adviceID, error)`；`OrderDraftStore.CreateDraft(ctx, scope, order) (orderID, error)`；`RunLocker.AcquireRun(ctx, runID) (Lease, error)`，`Lease{Renew, Release}`。
- L2：`agent.ToolProvider`，工具名见 `docs/mock-real-status.md`（weather.forecast、crop.phenology、field.profile、field.history、field.pest_survey、device.list 等）；失败以 `ToolResult.Status != "OK"` 表达。
- L3：`knowledge.NewStore(NewRepoReader(repo)).Open(ctx, ref)`、`NewLoader(store).Load(ctx, ref, tx, Situation)`（`ErrKBMiss`）、`calc.New(snap)` 的 `Candidates / Dosage / Dilution / PHIDate / Fertilizer / WaterVolume`，结果带 `Trace{Inputs, Formula}`。见 `docs/dev-log.md`「L3 代码」。

## 分工（两个子 agent 并行，各自 worktree）
- **L4-a 主链路**：`internal/agent/llm`（Eino ChatModel 薄封装：档位、超时、重试、token 计量、脱敏挂载点 `func(string) string` 默认原样 TODO(L5)、`rl:model:{tier}` 限流超限走降级；OpenAI 兼容实现用 `github.com/cloudwego/eino-ext/components/model/openai@v0.1.8`（本地模块缓存已有），读 env `ONEAPI_BASE_URL / ONEAPI_API_KEY / ONEAPI_MODEL`，未设置时只能用桩；另提供确定性桩 ChatModel 供单测 / 评测）；`internal/agent/graph`（compose Graph：classify[LLM] → enrich[工具并行] → load_knowledge → candidates → choose[LLM 只返回候选 ID 枚举] → compute[calc] → explain[LLM，数字用 {{n0}} 占位] → assemble → validate（裸数值拒收、selected ∈ candidates、citation 齐全）→ persist → to_order；KB_MISS / 工具失败 / 候选为空 → REFUSED 卡；降级分支 degraded=true）；`internal/agent/harness/runner`（持 `lock:run:{run_id}` 每 10s 续期并 Heartbeat，续期失败停止写库；callbacks 每节点 SaveStep）；AdviceCard → WorkOrder(DRAFT) 转换器（作业类 → 设备参数，dispatch_mode=DRY_RUN；观察类不建单）；`prompts/`（分层 + 版本号，prompt_version 写 RunState）与 `configs/model.yaml`（档位、温度、max_tokens、超时，可回滚）；在 `internal/app` 装配 graph 替换 `agent.Placeholder`（app.Deps 增加所需依赖）。
- **L4-b 存储 / 入口 / 评测**：`repository` 实现 RunStateStore / AdviceStore / OrderDraftStore / RunLocker（照抄 §6.5 SQL：run_step 行别名 upsert、advice_card `LAST_INSERT_ID(id)`、citation 按 uk_advice_seq 去重、episodic_memory INSERT IGNORE、work_order uk_advice + transition，同事务）；`migrations/0002_advice.{up,down}.sql`（advice_card、advice_citation、episodic_memory；不入库但必须能跑）；`service.AskService`（插 agent_run RUNNING → 异步 Ask(RunID) → 立即返回 run_id）+ `controller` `POST /api/v1/farms/{farm_id}/ask`（鉴权 Scope、参数校验、X-Request-Id、`rl:farm:{farm_id}:ask` 限流）+ `GET .../runs/{run_id}` 查卡；`internal/evalkit/grader/code` 五个打分器 `schema_valid / numbers_match_calc / product_in_candidates / outcome_match / must_call / budget`（表驱动含应失败），接入 evalkit Runner（Trial 保留 Card、跑全部打分器、报告列出分项）；cmd/eval infra 把样本 field 编码解析为 Scope/FieldID 填入 Question；`cmd/eval validate` 增加「样本参考解通过全部打分器」静态检查（验收 5）。

两边都可能改 `internal/app`，冲突由调度方合并时处理；各自只加自己需要的字段。
