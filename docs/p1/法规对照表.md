# 法规对照表（P1 · L3）

依据：P1 手册 §6.4 功能任务 6。数据源是 `policy/regulation_map.yaml`（生产与 eval 共用同一份），本表与该文件逐条对应；条目来源是 `docs/p1/法规清单初稿.md`。条款引用由法务填写，工程建议一律「待法务确认」，全表**待签字**。

## 判定方式

- `checker`：约束校验器判定，rule_id 指向 `internal/agent/guardrail/constraint` 注册表。
- `precondition`：法规前置条件，开票前最先判定，不要求 tool_call_id。
- `unmapped`：尚无工程判定。条目适用即写一条失败行 `reg:<id>`，作业单留草稿（失败关闭）。
- 启动期校验：`constraint.ParseRegulationMap`（`internal/agent/guardrail/constraint/regulation.go`）检查 checker / precondition 引用的 rule_id 已注册且种类一致，任一不符则 `cmd/server`、`cmd/eval` 启动失败（装配见 `internal/app/constraint.go`）。
- 拦截入口：`constraint.Reviewer.Review`（`reviewer.go`），由 `ApprovalService.Open` 在开票前调用。
