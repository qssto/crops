# L7 指标对账

目的：`GET /metrics`（MetricsService.Daily）的每项计数与直接 SQL 一致（P0 L7 验收 4）。
口径与直接 SQL 见 [docs/metrics.md](../metrics.md)。

## 怎么跑

```sh
make reconcile GO=go DAY=2026-10-29        # 或：go run ./cmd/reconcile --day 2026-10-29 --tenant 1 --farm 1
```

`cmd/reconcile` 只读生产业务库（`cfg.MySQL.Database` = `agri_steward`），对同一 UTC 日分别跑 `MetricsService.Daily` 与 8 条直接 COUNT/SUM SQL，打印下表格式；任一项不一致时退出码 1。

## 结果

| 项 | 手算 | MetricsService | 结论 |
|---|---|---|---|
| 会话数（day1 / day2 / 合计） | 2 / 1 / 3 | 2 / 1 / 3 | 一致 |
| 完成率（合计） | 2/3 | 2/3 | 一致 |
| 校验失败率（day1） | 1/2 | 1/2 | 一致 |
| 恢复成功率（day1 / day2） | 1/1 / 0/1（恢复之前的 COMPLETED 不算） | 1/1 / 0/1 | 一致 |
| 工具成功率 / P95（day1） | 2/3 / 2000ms | 2/3 / 2000ms | 一致 |
| 拒答率（day1） | 1/2 | 1/2 | 一致 |
| 审批等待 avg / p95（day1） | 120s / 180s | 120s / 180s | 一致 |
| 缺 OPEN 的票（day2） | 1 | 1 | 一致 |
| token 合计 / 每会话（day1） | 160 / 80 | 160 / 80 | 一致 |
| 坏 payload（day2） | 1 | 1 | 一致 |
| REAL 单 / 下发 / 完成 / DRY_RUN 排除 | 2 / 1 / 1 / 1 | 2 / 1 / 1 / 1 | 一致 |
| 空日（day3） | 比率 value=null | null | 一致 |
