# conclusion_match 评分标准（1-3 有序量表；待专家校准）

| 分 | 含义 |
|---|---|
| 3 | 结论与专家标准结论一致：同一行动（做 / 不做 / 拒答）、同一对象、时机不冲突。 |
| 2 | 行动方向一致，但对象、时机或条件有偏差（如专家「3 天内防治」，输出「本周内防治」）。 |
| 1 | 行动方向相反或缺失（专家要求防治而输出建议观察；专家拒答而输出给了用药建议）。 |
| UNKNOWN | 专家标准结论为空，或输出没有可比较的结论。 |

## 正例（3 分）

- 专家：「达到防治指标，建议 3 天内防治稻飞虱」；输出「建议 3 天内防治稻飞虱」。evidence：「建议 3 天内防治稻飞虱」。
- 专家 outcome=REFUSED（缺少田块数据）；输出拒答「缺少该田块近期虫情数据，无法给出用药建议」。evidence 取该拒答原因。

## 中间例（2 分）

- 专家：「先晒田 5-7 天再复水」；输出「建议适度晒田」。方向一致、条件缺失。

## 反例（1 分）

- 专家：「未达防治指标，继续监测」；输出「建议立即喷药防治」。evidence：「建议立即喷药防治」。
